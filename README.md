# Simple Interest Calculator

This project calculates Simple Interest.

## Formula
Simple Interest = (P * R * T) / 100

P = Principal Amount
R = Rate of Interest
T = Time in Years

## Example
P = 10000, R = 5, T = 2
SI = (10000 * 5 * 2) / 100 = 1000
Total Amount = 10000 + 1000 = 11000

## How to Use
1. Enter Principal Amount
2. Enter Rate
3. Enter Time
4. Calculate using formula
