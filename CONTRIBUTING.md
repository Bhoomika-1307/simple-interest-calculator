# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for considering contributing to this project!

## How to Contribute

### 1. Bug Reports
If you find a bug, please open an issue and describe:
- What you expected to happen
- What actually happened
- Steps to reproduce the bug

### 2. Bug Fixes
- Fork this repository
- Create a new branch for your fix
- Fix the bug and test it
- Submit a Pull Request

### 3. Documentation Improvements
You can improve the README, add comments, or fix spelling mistakes. All documentation improvements are welcome.

### 4. Enhancements and Ideas
Have an idea to make this calculator better? For example, adding compound interest or a new design?
Open an issue and share your idea. All enhancements and ideas are welcome.

## Steps to Contribute

1. Fork the repository
2. Clone your fork to your computer
3. Create a new branch: `git checkout -b my-fix`
4. Make your changes
5. Commit: `git commit -m "Fix bug"`
6. Push: `git push origin my-fix`
7. Open a Pull Request

## Code of Conduct

Please follow our Code of Conduct in CODE_OF_CONDUCT.md. Be kind and respectful to everyone.

Thank you for your contributions!
